El alumnado deberá diseñar y desarrollar una base de datos relacional completa que dé respuesta a una
situación real o simulada (sencilla), siguiendo todas las fases del ciclo de vida de una base de datos: análisis
de requisitos, diseño conceptual (modelo ER), diseño lógico, diseño físico e implementación en un sistema
gestor de bases de datos (SGBD).
Descripción del Proyecto
Cada grupo propondrá una realidad cercana o una simulación sencilla que requiera la gestión estructurada
de información.
A partir de esa realidad o simulación, se deberán desarrollar las siguientes fases:
1. Análisis de requisitos (RA6)
Identificación de las necesidades de información.
Recogida de requisitos funcionales (qué debe hacer el sistema, es decir, qué operaciones debe
permitir realizar a los usuarios y qué información debe gestionar).
2. Diseño conceptual (RA6)
Elaboración del modelo entidad-relación (ER) detallado.
Identificación de entidades (aconsejable entre 5 y 7), atributos, claves primarias, relaciones,
cardinalidades y restricciones.
3. Diseño lógico (RA6)
Transformación del modelo ER al modelo lógico relacional.
Elaboración del esquema relacional: definición tablas, claves primarias y ajenas, dominios y
restricciones.
